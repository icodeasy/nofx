## 💡 核心教训

### 1. 暴跌后的"4-6小时冷静期"至关重要

**为什么需要冷静期:**
- 暴跌后余震可能持续数小时
- 市场情绪需要时间恢复
- 技术指标需要重新确认

**建议的冷静期规则:**
```
IF (15分钟跌幅 > 1.5% AND 成交量 > 正常5倍):
    标记为"暴跌事件"
    冷静期 = 4-6小时
    在冷静期内:
        - 禁止开新仓
        - 或信心度自动下调20-30%
        - 或仓位限制在最小值
```

### 2. 资金流的时间窗口问题

**问题:**
- 1小时资金流可能包含暴跌中的抄底资金
- 这些资金已经进场,不代表当前还有买盘

**解决方案:**
```
开多条件 (多周期资金流确认):
- 当前15分钟资金流 > 0
- 最近1小时资金流 > 0
- 最近4小时资金流 > 0
(至少满足2个,理想情况全满足)
```

### 3. 止损空间应随波动率调整

**当前问题:**
- 固定止损百分比在暴跌后不够用
- 0.78%在高波动环境中太容易被触发

**动态止损建议:**
```
正常市场: 止损距离 = 1-1.5%
暴跌后6小时内: 止损距离 = 2-2.5%
波动率(ATR)高于正常2倍: 止损距离 = 1.5 × ATR

具体计算:
IF 暴跌后 < 6小时:
    stop_loss_distance = max(2%, 1.5 × ATR)
ELSE:
    stop_loss_distance = max(1%, ATR)
```

### 4. 信心度应考虑市场状态

**问题:**
- 当前信心度只基于信号强度
- 没有考虑市场环境(暴跌、逆势等)

**信心度调整因子:**
```
基础信心度 = 85% (基于资金流和OI)

调整因子:
- 暴跌后6小时内: -20%
- 逆势交易(4h/12h负): -10%
- 负面Funding Rate: -5%
- 止损空间 < 1%: -10%

最终信心度 = 85% - 20% - 10% - 5% - 10% = 40%
→ 不满足开仓条件(需≥75%)
```

### 5. 支撑有效性需要验证

**问题:**
- 单次反弹不足以确认支撑有效
- 暴跌击穿的支撑位可能已失效

**支撑确认规则:**
```
支撑位反弹 + 以下任一条件:
1. 价格在支撑位上方停留 ≥ 2小时
2. 至少2次测试支撑而不破
3. 成交量恢复至正常水平 (< 2倍正常)
4. 资金流连续3个周期为正
5. 价格创出高于暴跌前的高点
```

def detect_crash(candle_15m):
    price_drop_pct = (candle_15m.close - candle_15m.low) / candle_15m.close
    volume_ratio = candle_15m.volume / avg_volume_15m

def check_cooldown(current_time, crash_time):
    if crash_time is None:
        return True  # 没有暴跌,可以交易

    hours_since_crash = (current_time - crash_time) / 3600
    if hours_since_crash < 4:
        return False  # 仍在冷静期,不可交易

    return True

```python
def calculate_stop_loss(entry_price, atr, hours_since_crash):
    if hours_since_crash < 6:
        # 暴跌后使用更大止损
        stop_distance_pct = max(0.02, 1.5 * atr / entry_price)
    else:
        # 正常市场
        stop_distance_pct = max(0.01, atr / entry_price)

    stop_loss_price = entry_price * (1 - stop_distance_pct)
    return stop_loss_price, stop_distance_pct
```

def adjust_confidence(base_confidence, market_state):

## 📚 学习总结

### 这笔交易教会我们:

1. **强信号 ≠ 好时机**
   - 资金流再强也要看市场状态
   - 暴跌后的反弹往往是陷阱

2. **时机比信号更重要**
   - 同样的信号在不同时机结果完全不同
   - 暴跌后至少要等4-6小时

3. **高信心度需要全面评估**
   - 不能只看资金流和OI
   - 必须考虑环境、趋势、波动率等

4. **防御性规则是必要的**
   - 不能依赖AI自动判断所有风险
   - 必须有硬性的保护规则

5. **系统性错误必须修复**
   - 连续两次同样错误说明是系统缺陷
   - 必须从规则层面根本解决
