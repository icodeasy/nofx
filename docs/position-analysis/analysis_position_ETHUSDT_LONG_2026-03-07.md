- 已经在这笔交易中体现,应该正式加入规则

- 不只看当前1小时,还要看资金流的**变化趋势**
- 入场: -2.42M → 出场: +5.94M (转变明显)
- 可以设置"资金流反转"指标

### 3. 阶梯止盈策略
- 第一目标: +2% (平仓50%)
- 第二目标: +4% (平仓30%)
- 第三目标: +6% (平仓20%)

### 4. 移动止损
- 当浮盈 ≥ +0.5% 时,移动止损到入场价
- 当浮盈 ≥ +1.5% 时,移动止损到 +0.5%
- 保护利润同时给趋势发展空间

### 5. 逆势交易的额外过滤器
- 如果4h/12h/24h均为负,要求更强的信号:
  - 机构资金必须流入 (而非流出)
  - OI增加必须 >1%
  - 价格必须突破关键阻力
